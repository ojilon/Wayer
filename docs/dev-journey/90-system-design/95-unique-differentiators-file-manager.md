# 95 — Unique differentiators: what makes Wayer NOT "another file manager"

## Goal
Your ask: "modern unique things this app [gets] that previous file managers don't have."

## Touches
- Everything: organizer (24), trash (39), morning scan (40), stale nudge (41), Files rethink (70), breadcrumbs (55), Home (73), transfer ideas (68)

## Thesis (propose, then prove with 2 ships)
Old managers = browse + ops. Wayer = **answer-first**: "what can I reclaim? what's stale? what's already on PC? where did it go?"

## Differentiator shortlist (score value/risk, ship 2)
1. **Reclaim answer card (Home):** `X GB in dups + Y GB old-large + Z GB stale APKs — [Review each]` from ONE morning scan (40). No other manager aggregates across utilities. (Needs 30/34/37 + 73.)
2. **Verified-duplicates with keeper AI-lite:** "keep newest in Camera, trash Download copies" (33 smart keeper) + byte-confirm badge (32). Trust > cleverness.
3. **Send-&-sort bundle (68.5):** queue + PC auto-sort by shared categories (68.3). Two apps, one tap.
4. **Undo-everything (24 stretch + 39):** every destructive op -> trash + snackbar Undo + inverse plan. Market it: "the file manager with Undo."
5. **Stale-nudge with names (41):** "IMG_2019_beach.mp4 (1.1GB) untouched 3y — Review?" Names beat "clean junk!" vibes.
6. **Provenance:** every file row can show `why here?` (organized from X on DATE via report? received from PC Y?). Needs report retention — spec only.
7. **Parcel/drop (68.6):** USB-sneakernet when hotspot fails. Unsexy, unforgettable when needed.

## Guided tasks
1. Score 1–7, pick 2 (likely 1 + 4). Write 1-page spec each (data source, UX, safety).
2. Ship smallest slice of #1 (aggregate card reading EXISTING scan files — no new engine).
3. Instrument: which card gets tapped? (prefs counter, no analytics lib.) Let usage pick the next ship.
